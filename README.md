
# 🤖 AI Landing Page Generator

An AI-powered web application that generates customized landing pages from natural language prompts.

The project explores how artificial intelligence can simplify website creation by turning user instructions into customized web pages.

## ✨ About the Project

AI Landing Page Generator is a web application developed to experiment with AI-powered website generation.

Users can describe the type of page they want to create, and the application uses the Grok API to generate a page based on their instructions.

This project is part of my journey as a developer, combining web development, backend fundamentals, and AI integration.

## 🚀 Features

- 🤖 AI-powered landing page generation
- 💬 Natural language prompts
- 🎨 Customized page creation based on user instructions
- 🌐 Web-based interface
- 🔌 Integration with the Grok API

## ⚙️ Getting Started

### Prerequisites

- Node.js and npm installed
- A Grok API key, if required by the current configuration

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/luizhtech/Gerador-de-Paginas-.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Gerador-de-Paginas-
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Configure your environment variables according to the server implementation.

5. Start the application using the command configured in `package.json`.

## 🔐 Security

API credentials should be stored in environment variables and kept on the server side.

Never expose API keys in frontend code or commit secrets to the repository.
